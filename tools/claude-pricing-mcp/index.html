Claude Pricing MCP Server

A free, remote MCP server that lets your AI assistant answer "what will this cost on Claude?" with current prices instead of guesses. It knows every current Claude model, prompt caching and the Batch API discount. No sign-up, no API key, nothing to install.

Server URL

https://agentwright.app/mcp

Transport: Streamable HTTP. Read-only, stateless, no authentication. We do not log or store your requests.

Add it to your client

Claude Code

claude mcp add --transport http claude-pricing https://agentwright.app/mcp

Claude desktop app and claude.ai: Settings → Connectors → Add custom connector, then paste https://agentwright.app/mcp as the URL.

Cursor (~/.cursor/mcp.json)

{
  "mcpServers": {
    "claude-pricing": { "url": "https://agentwright.app/mcp" }
  }
}

VS Code (.vscode/mcp.json)

{
  "servers": {
    "claude-pricing": { "type": "http", "url": "https://agentwright.app/mcp" }
  }
}

Where the prices come from

The server reads the same price table as our Claude API cost calculator, checked against the official Claude pricing page. Every answer states the date of the table it used. If you spot a wrong price, tell us at hello@agentwright.app.

The source code is public: functions/mcp.ts. It is a small, dependency-free implementation of the MCP Streamable HTTP transport on Cloudflare Pages Functions, so it also works as an example of a remote MCP server.

Agentwright Starter is a Next.js codebase for Claude-powered SaaS that turns these estimates into real numbers: per-user token tracking in Postgres, plan caps and rate limits, a streaming agent loop with tool calls, an MCP client, evals and auth. Launch price $99.
