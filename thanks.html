Get running in 5 minutes

  1. Unzip, then cd into the folder and run npm install.
  2. Copy .env.example to .env.local and add your ANTHROPIC_API_KEY, a Postgres DATABASE_URL and an AUTH_SECRET.
  3. Run npm run db:migrate, then npm run dev and open localhost:3000.
  4. Read docs/setup.md and docs/deploy.md in the zip for GitHub login, billing webhooks and deploying to Vercel + Neon.
